# 保持する状態を設定だけに限る

## Context and Problem Statement

`nag` を引数なしで起動して棋譜を選べるようにすると、棋譜の置き場所を知る必要が生じる。
engine の実行パスと悪手の閾値も、どこかから読む必要がある。
どちらも値そのものは既存の判断で決まっているが、置き場所は決まっていない。

一方で、閲覧した棋譜の一覧、最後に見た局面、解析結果の写しといった値も、保持すれば利便性が上がる。
どこまでを PGN の外に持つかを決める。

## Decision Drivers

* 引数なしの起動で棋譜を選べるようにしたい。
* 保持した値と実際のファイルが食い違う状態を作りたくない。
* 注釈付き PGN 1 ファイルで完結するという性質を壊したくない。

## Considered Options

* 設定だけを持ち、それ以外の状態は持たない。
* 設定に加えて、閲覧履歴や最後に見た局面を持つ。
* 設定に加えて、解析結果の写しを cache として持つ。

## Decision Outcome

設定だけを持ち、それ以外の状態は持たない。

設定が持つのは、engine の実行パス、悪手の閾値、棋譜を置くディレクトリの 3 つになる。
いずれの置き場所もこの ADR で初めて決める。
ADR-0006 は閾値をファイルに保存しないと決めているが、では何から読むかは決めていない。

形式は TOML にする。
Rust から読み書きが素直で、追加の解析を要さない。

置き場所は `etcetera` crate が返す設定ディレクトリに置く。
各 OS の慣行は crate ごとに解釈が割れるため、規約ではなく実装を名指しして分岐の余地を無くす。

当初は `directories` を名指ししていたが、その依存が MPL-2.0 の crate を引き込む。
GPL-3.0 とは両立するものの、許可するライセンスを広げる理由が他に無いため、依存が MIT と Apache-2.0 だけで済む `etcetera` に替えた。

環境変数と設定ファイルの優先順位は、ここでは決めない。

### 設定は読むだけにする

設定ファイルは利用者が書き、`nag` は読むだけにする。
`nag` が書き込むのは、`analyze` が指定された出力先に生成する注釈付き PGN だけになる。

これにより、保持した状態が古くなるという問題が起きる箇所が存在しなくなる。

### 一覧の作り方

引数なしの起動は、設定されたディレクトリ直下の `.pgn` を一覧にする。
サブディレクトリは辿らない。

注釈の有無で絞り込まない。
ADR-0001 が未注釈の PGN も再生できる経路を残すと決めているため、一覧の時点で中身を読んで振り分ける理由が無い。
拡張子だけで判断するので、一覧を作るためにファイルを開く必要も無い。

設定ファイルが無い場合、またはディレクトリが存在しない場合は、設定の書き方を示して終了する。
空の一覧を出すと、設定の誤りとファイルが 1 つも無い状態が区別できない。

`nag view <path>` は設定に依らず動く。
`path` にはファイルとディレクトリの双方を受け付け、ディレクトリなら同じ規則で一覧にする。
一覧の経路を 2 つ持たないためで、これはこの ADR で決める新しい動作になる。

### 却下した案

解析結果の写しを cache として持つ案は採らない。
写しと実体が食い違ったときに、どちらを正とするかを決める必要が生じる。
一覧の生成にかかるのはディレクトリの走査だけなので、cache が省ける仕事も小さい。
走査の件数が問題になった時点で改めて判断する。

閲覧履歴と最後に見た局面も、今は持たない。
ファイルの移動・削除・再解析のたびに、保持した値と実体の食い違いをどう扱うかを決める必要が生じる。

### Confirmation

設定ファイルを削除した状態で `nag view <file>` が動くことを確認する。

統合テストを実行した後、設定ディレクトリと `HOME` の下にファイルが作られていないことを確認する。
`analyze` が指定された出力先に書くことだけが例外になる。

## Consequences

### Good

* 保持する値が設定 1 つに限られ、実体との食い違いが起きる箇所が増えない。
* 棋譜の一覧がディレクトリの内容そのものになり、無効化を考えずに済む。
* 設定を消しても、パスを指定する経路は動き続ける。
* 設定が対局ごとの値を持たないため、注釈付き PGN 1 ファイルで完結する性質が保たれる。

### Bad

* 棋譜を複数のディレクトリに分けている場合、引数なしの起動で出るのは設定した 1 つだけになる。
  パスを指定する経路が残るため、閲覧そのものは阻害しない。
* 前回見ていた局面が引き継がれない。
  主な使い方である悪手を辿る閲覧では、ADR-0009 が割り当てた `G` と上下のキーで数打鍵のうちに目的の手へ戻れるため、引き換えとして受け入れる。
* サブディレクトリに置いた棋譜が一覧に出ない。
  ディレクトリを指定して開く経路が残るため、閲覧そのものは阻害しない。
